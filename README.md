# Color Holds

A [BepInEx](https://github.com/BepInEx/BepInEx) mod for **White Knuckle** that recolors the climbable holds. Pick any color you like instead of the default red, right from an in-game menu.

## Features

- Recolor all holds to any color you choose
- Color wheel for picking the color
- Brightness slider
- Shader strength slider (blends from your chosen color down to the default red / no shader)

## Requirements

- White Knuckle (Mono build)
- [BepInEx](https://github.com/BepInEx/BepInEx) installed in the game folder

## Installation

1. Install BepInEx (Mono) into your White Knuckle folder and launch the game once, so the `BepInEx/plugins/` folder gets created.
2. Download the latest `ColorHolds.dll` from the [Releases](../../releases) page (also available on [Thunderstore](https://thunderstore.io/c/white-knuckle/p/RZT/ColorHolds/)).
3. Put the DLL into `BepInEx/plugins/`.
4. Launch the game.

## Usage

Open the mod menu in game and choose your color with the color wheel. Adjust brightness and shader strength with the sliders.

## Compatibility

Tested with the current version of White Knuckle (Mono build). A game update may break the mod, so if something stops working, open an issue.
